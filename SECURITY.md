# Security Policy

## Reporting Security Vulnerabilities

We appreciate responsible disclosure of security issues in History AI Roleplay.

To report a vulnerability:
- Email directly to: `yashpatadiya1724@gmail.com`
- Include a description of the issue, affected endpoints or files, and proof-of-concept steps.
- We aim to review and acknowledge all security disclosures within 48 hours.
- Please do not open public GitHub issues regarding unresolved vulnerabilities.
